# MouseMotionEffectプラグイン

設定画面の枠の中を **マウスでドラッグするだけ** で、移動の軌跡とイージングを自動生成してアイテムを動かす映像エフェクトです。

## 使い方

1. タイムライン上のアイテムを選択し、映像エフェクトから **「マウス移動」**（カテゴリ: アニメーション）を追加します。
2. 「軌跡」の枠の中を、左ボタンでドラッグします（白い丸が動きます）。
3. ボタンを離すと、軌跡と速さの変化が記録されます。
   - 緑の点が開始、赤の点が終了です。
   - 枠の下の曲線が、実際に使われるイージング（横: 時間、縦: 進み具合）です。
   - 「▶ 再生」で動きを確認できます。
4. 動きはアイテムの長さ全体にわたって再生されます。
5. 気に入らなければ、もう一度ドラッグし直すか「クリア」を押してください。

### 再生速度（切り替え）

| 設定 | 内容 |
| --- | --- |
| **タイムライン終了まで**（初期値） | 動きをアイテムの長さ全体に引き伸ばします。 |
| **通常速度（記録した時間）** | ドラッグにかかった時間のまま動き、終わったら終点で止まります。アイテムが記録より短いと、途中で終わります。 |

「▶ 再生」のプレビューも、この設定に合わせた長さで動きます。

### イージング方式（切り替え）

| 方式 | 内容 |
| --- | --- |
| **記録そのまま**（初期値） | 実際にドラッグしたときの速さの変化（止まった・急いだ・ゆっくりになった）をそのまま使います。 |
| **プリセット** | 「イージング」「イージングの向き」の設定を使います。ドラッグ直後は、記録に最も近いプリセットが自動で入ります。手動で変えることもできます。 |

- 「プリセット再判定」ボタン: いまの記録（手ぶれ補正後）に最も近いプリセットを選び直します。
- 旧バージョンで作った記録（速さの情報がないもの）は、方式が「記録そのまま」でもプリセットで動きます。もう一度ドラッグし直すと速さも記録されます。

### 手ぶれ補正

「手ぶれ補正」を **弱 / 標準 / 強 / 最強** にすると、ドラッグ中の手の細かな震えを取り除いて、軌跡と速さをなめらかにします（初期値: オフ）。

- 枠の中には、補正後の軌跡（水色）と補正前の軌跡（灰色の点線）が重ねて表示されます。
- 強さはあとから変えられます。記録し直す必要はありません。
- 始点と終点は動きません。強くするほど、急なカーブの角が丸くなり、速さの細かな変化も消えます。

### 仕組み

- **記録**: ドラッグの座標と時刻を保存します（最大300点）。
- **手ぶれ補正**: 時間方向のガウスフィルタ（標準偏差: 弱 25ms / 標準 60ms / 強 110ms / 最強 180ms）で、座標を均します。
- **軌跡**: 補正後の座標列を折れ線に簡略化します（最大24点）。
- **記録そのまま**: 各時刻でドラッグが軌跡のどこまで進んでいたかを求め、なめらかな曲線にして使います。行って戻る軌跡でも、進み具合が崩れないようにしています。
- **プリセット判定**: 上の速さの変化を、Linear / Sine / Quad / Cubic / Quart / Quint / Expo / Circ / Back × In / Out / InOut / OutIn と比べ、最も近いものを選びます。
- **移動量**: 開始点からの変位としてアイテムの位置に加算されます。アイテム自体の X / Y はそのままなので、アイテムの置き場所は自由に決められます。

## うまく動かないとき

- **動きが細かく震える**: 「手ぶれ補正」を上げてください。
- **動きの上下が逆**: 「上下を反転」をオンにしてください。

## 既知の制限

- 動かす操作はタイムライン上ではなく、設定内の枠で行います（YMM4 のプラグイン用 API に、タイムライン上のアイテムを直接編集する公開手段がないため）。
- 動きはアイテムの先頭から始まります。途中の区間だけ動かしたい場合は、アイテムを分割してそれぞれに適用してください。
- AviUtl への出力（exo）には対応していません。
